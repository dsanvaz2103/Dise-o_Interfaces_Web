Tema 2: Hojas de estilo CSS

🎨 Conceptos Fundamentales de CSS

CSS permite separar el contenido (HTML) de la presentación. Algunos pilares clave son:

  • Selectores: Básicos (etiqueta, clase ., ID #) y Combinadores (descendientes, hijos directos >).
  • Unidades de medida: Absolutas (px) y Relativas (em, rem, %, vh/vw) para diseños adaptables.
  • Modelo de Caja: Control de margin, border, padding y el contenido.

✨ Buenas Prácticas y Código Limpio

Para mantener un proyecto escalable es vital seguir reglas de organización:

  • Nombres Semánticos: Usar .main-header en lugar de .header1.
  • Reutilización: Crear clases genéricas como .btn y modificadores como .btn-primary.
  • Comentarios: Dividir el archivo en secciones (Global, Header, Main, Footer).
  • Validación: Comprobar siempre el código con el validador del W3C.

Tema 3: Preprocesadores SASS y Less

⚙️ ¿Qué son los preprocesadores?

Son herramientas que extienden las capacidades de CSS permitiendo usar lógica de programación para generar hojas de estilo más limpias y eficientes.

  • SASS (Syntactically Awesome Style Sheets): El más popular, utiliza archivos .scss.
  • Less (Leaner Style Sheets): Muy similar a SASS, pero con algunas diferencias en sintaxis de variables.

🧩 Conceptos Potentes en SASS

  • Variables: Permiten almacenar colores o tamaños para reutilizarlos.
  • Anidamiento: Permite escribir selectores CSS dentro de otros reflejando la jerarquía.
  • Mixins: Bloques de código reutilizables con parámetros.
  • Operadores: Permiten realizar cálculos matemáticos (+, -, *, /).
  • Interpolación: Inserción de valores dinámicos usando #{}.

Tema 4: Maquetación con Flexbox y Grid Layout

📏 Flexbox vs CSS Grid

Situación Flexbox CSS Grid
Dimensión Unidimensional (Fila O Columna) Bidimensional (Fila Y Columna)
Uso ideal Componentes (Menús, botones alineados) Estructura general de la página (Layout)

🧩 Conceptos Clave

  • Flexbox: display: flex;, alineación con justify-content y align-items.
  • Grid: Rejillas con grid-template-columns, unidad fr y gap.
