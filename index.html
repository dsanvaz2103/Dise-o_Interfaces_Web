Tema 2: Hojas de estilo CSS

🎨 Conceptos Fundamentales de CSS

CSS permite separar el contenido (HTML) de la presentación. Algunos pilares clave son:

  • Selectores: Básicos (etiqueta, clase ., ID #) y Combinadores (descendientes, hijos directos >).
  • Unidades de medida: Absolutas (px) y Relativas (em, rem, %, vh/vw) para diseños adaptables.
  • Modelo de Caja: Control de margin, border, padding y el contenido.

✨ Buenas Prácticas y Código Limpio

Para mantener un proyecto escalable es vital seguir reglas de organización:

  • Nombres Semánticos: Usar .main-header en lugar de .header1.
  • Reutilización: Crear clases genéricas como .btn y modificadores como .btn-primary.
  • Comentarios: Dividir el archivo en secciones (Global, Header, Main, Footer).
  • Validación: Comprobar siempre el código con el validador del W3C.

Tema 3: Preprocesadores SASS y Less

⚙️ ¿Qué son los preprocesadores?

[cite_start]

Son herramientas que extienden las capacidades de CSS permitiendo usar lógica de programación para generar hojas de estilo más limpias y eficientes[cite: 3].

    [cite_start]
  • SASS (Syntactically Awesome Style Sheets): El más popular, utiliza archivos .scss[cite: 1, 10].
    • [cite_start]
  • Less (Leaner Style Sheets): Muy similar a SASS, pero con algunas diferencias en sintaxis de variables (usa @ en lugar de $)[cite: 11].

🧩 Conceptos Potentes en SASS

    [cite_start]
  • Variables: Permiten almacenar colores o tamaños (ej. $color-principal: #3498db;) para reutilizarlos en todo el proyecto[cite: 11, 12].
    • [cite_start]
  • Anidamiento: Permite escribir selectores CSS dentro de otros, reflejando la jerarquía del HTML y evitando repeticiones[cite: 11, 12].
    • [cite_start]
  • Mixins: Bloques de código reutilizables que pueden recibir parámetros, ideales para prefijos o estilos complejos[cite: 11, 12].
    • [cite_start]
  • Operadores: Permiten realizar cálculos matemáticos (+, -, *, /) directamente en el CSS (ej. width: 100% / 3;)[cite: 12, 15].
    • [cite_start]
  • Interpolación: Inserción de valores dinámicos en selectores o propiedades usando #{}[cite: 27, 28].

Tema 4: Maquetación con Flexbox y Grid Layout

📏 Flexbox vs CSS Grid

Según las directrices de diseño modernas, la elección entre Flexbox y Grid depende de la dimensión del diseño:

Situación Flexbox CSS Grid
Dimensión Unidimensional (Fila O Columna) Bidimensional (Fila Y Columna)
Uso ideal Componentes (Menús, botones alineados) Estructura general de la página (Layout)

🧩 Conceptos Clave

  • Flexbox: display: flex;, alineación con justify-content y align-items.
  • Grid: Rejillas con grid-template-columns, unidad fr y gap.

Tema 5: Imágenes y Software de gestión de recursos gráficos

1. Análisis Visual y Compositivo: LEGO (Home)

  • Imagen principal: Un set destacado (como el Castillo de Disney o un coche de Technic) montado y en un entorno real o fantástico, a menudo con niños o adultos interactuando con él.

  • Punto focal: El producto terminado. LEGO no vende piezas sueltas en su portada; vende el orgullo de haberlo construido. El ojo se va directo a la complejidad del modelo.

  • Peso visual: Muy alto en los colores primarios (rojo, amarillo, azul). Las cajas de los productos tienen mucho peso visual debido a su diseño gráfico icónico.

  • Balance compositivo: Balance Modular. La web imita la naturaleza del producto: bloques de contenido claramente definidos que encajan unos con otros. Es una estructura limpia pero muy colorida.

  • Función de cada imagen: Inspiradora y Técnica. Hay fotos del estilo de vida (el set decorando un salón) y fotos de detalle (las minifiguras o funciones móviles).

  • ¿Valor o decorativa?: Aporta un valor de confianza. Ver el set construido desde varios ángulos asegura al comprador que el resultado final merece el esfuerzo.

2. Rendimiento y Comparativa

LEGO maneja miles de referencias, lo que requiere un sistema de gestión de imágenes muy robusto para no colapsar el navegador.

Web Impacto en Rendimiento Experiencia de Carga
LEGO Medio-Alto (Mucho detalle) Carga por bloques; las imágenes críticas aparecen primero
The Verge (Negativa) Alto (Muchos trackers/anuncios) La página suele "dar saltos" mientras cargan los banners de publicidad
Gov.uk (Rápida) Mínimo No usa imágenes si no son estrictamente necesarias

3. Identidad, UX y SEO

  • Identidad de marca: El amarillo LEGO domina los botones y llamadas a la acción. El uso de la tipografía redondeada evoca amabilidad y seguridad para los padres.

  • Influencia en la UX: Uso de microinteracciones. Al pasar el cursor sobre un set, a menudo la imagen cambia para mostrar la caja o el interior del modelo, lo que satisface la curiosidad del usuario sin cambiar de página.

  • Elementos SEO: Los nombres de los productos son muy específicos (ej: "LEGO 75192 Star Wars Millennium Falcon"). Google adora esta precisión porque coincide exactamente con lo que el coleccionista escribe en el buscador.

  • Accesibilidad: Las imágenes de producto tienen un zoom de alta calidad que se puede controlar con el teclado, permitiendo a personas con visión reducida ver los detalles sin perder el contexto.

    • 4. Memorias: Datos vs. Historias

  • Memoria Semántica (Datos): Idealista

    Buscas "Piso en Madrid, 2 habitaciones, 800€". Es una web de consulta rápida de datos. Tu cerebro almacena cifras y ubicaciones, no emociones.


  • Memoria Episódica (Historias): LEGO (Sección "Adultos Bienvenidos")

    Esta sección te cuenta la historia de un adulto relajándose tras el trabajo. No te vende "plástico ABS", te vende un momento de desconexión. Favorece la memoria episódica al asociar el producto con un recuerdo de bienestar o un "episodio" de relax en tu vida.

    • 5. Core Web Vitals (CWV) aplicados a tu Web

    1. LCP (Carga): Si usas imágenes de gran formato (como los sets de LEGO), asegúrate de que el servidor soporte HTTP/2 o HTTP/3. Esto permite que el navegador descargue varias imágenes a la vez en lugar de una por una.

     2. INP (Interactividad): En una tienda online, el filtrado (por precio, edad, etc.) debe ser instantáneo. Si el usuario marca "Star Wars" y la web tarda 2 segundos en reaccionar, el INP será pobre.

    3.CLS (Estabilidad):

    Error común: Los banners de "Oferta" que aparecen de repente arriba del todo.

    Solución: Reserva siempre ese espacio en tu diseño aunque el banner aún no haya cargado. Así nada se moverá de sitio.
